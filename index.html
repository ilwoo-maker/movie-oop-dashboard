1. 상속 구조 확인

왼쪽 패널에서 MovieADT → Movie → 장르별 영화 클래스 관계를 확인합니다.

2. 객체 클릭

객체 카드를 클릭하면 display()와 get_recommendation() 실행 결과가 출력됩니다.

3. 다형성 비교

Movie 배열 전체 실행 버튼으로 같은 메서드 호출이 객체별로 다르게 동작함을 확인합니다.

부모 타입 배열 예시

const movieList = [
  new ActionMovie(...),
  new RomanceMovie(...),
  new HorrorMovie(...)
];

movieList.forEach(movie => {
  movie.get_recommendation();
});
